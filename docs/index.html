Gen-Music: Real-Time AI Instrumental Music & Interactive Live DJ Sessions

A modern, professional CLI for generating instrumental music with Google's Lyria models (Lyria 3 Clip, Lyria 3.5, and Lyria Realtime) featuring automated prompt optimization and live DJ sessions.

uv tool install --python 3.12 git+https://github.com/charles-forsyth/generate-music.git
View Repository Explore Terminal Output

Key Capabilities

Designed and tuned for modern terminal workflows and automated pipelines.

✨

Lyria 3 Clip & 3.5 Full Tracks

Generates high-fidelity preview clips (<=30s) or full-length tracks with BPM and duration control.

✨

Interactive Live DJ Mode

Real-time interactive session via Lyria Realtime for responsive music manipulation.

✨

Prompt Enhancement

Gemini-powered prompt optimizer expands terse ideas into rich instrumental arrangements.

✨

Instant Audio Playback

Direct playback via system audio or background generation with history rerun tracking.

Usage Examples

Quick command recipes for terminal operations.

Preview Instrumental Clip

Generate and immediately play 30s track:

gen-music "Lo-fi hip hop beat with smooth rhodes chords and rain" -d 30 -p

Full-Length Mastered Track

Produce 60s track exported to MP3:

gen-music "Cinematic orchestral build with epic percussion" -d 60 -o epic.mp3

Live Interactive DJ Session

Launch interactive live Lyria DJ engine:

gen-music --live

Set Tempo & Optimize

Optimize prompt and enforce 72 BPM:

gen-music "Ambient synthesizer drone" --bpm 72 --optimize -p
